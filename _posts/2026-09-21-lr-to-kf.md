## 1. The basics

In case you aren't familiar (and if you are, a review is always useful) we will go over the basic ideas and techniques behind Bayesian inference.
There are many philosophical differences between Bayesian inference and frequentist inference. The main difference is how each school of thought interprets "probability." A Bayesian defines probabilities roughly as your degree of belief that an event will occur rather than the long run frequency in which an event will occur. 
This allows for the formation of models where the uncertainties of a system are taken into account and prior beliefs are incorporated. We can always update these probabilities, or "beliefs", in the case of new evidence.
Hopefully, by the end of this DRP, you will understand why Bayesian inference is adept for the type of dynamic estimation problems that motivate filtering and smoothing! But it's okay if that is not clear right now.

Here are some of the basic tools and terminology that is used in Bayesian inference:

- **Prior model**

The prior model contains preliminary information about the parameter(s) we want to learn. This consists of subjective beliefs about the possible, impossible, likely, and unlikely values of the parameter(s) before we observe any data.
We usually denote the parameters with $\mathbf{\theta}$ so the prior probability is just $p(\mathbf{\theta})$.

- **Measurement model (likelihood)**

The true parameters and the data usually have a casual, but misspecified and/or noisy relationship. It's most likely up to us (statisticians) to figure out what relationship is and write it down. 
We denote the measurement model by 

$$p(\mathbf{y} \mid \mathbf{\theta}).$$

(If you are not familiar with conditional probability, recall that $p(A \mid B) = p(A \cap B)/p(B)$.)
In plain English, this is the probability of observing your data, $\mathbf{y}$, given some value of the parameters.

We want to learn something about our parameters _given_ the data we have observed. Using the probabilistic notation, we would like to say something about $p(\mathbf{\theta} \mid \mathbf{y})$ and right now we have our prior model and a measurement model.
This is where the _Bayes_ part of Bayesian inference comes in. **Bayes' theorem** gives a rule for inverting conditional probabilities. 
Specifically, Bayes' theorem says, for any events $A$ and $B$, 

$$p(A \mid B) = \frac{p(B \mid A)p(A)}{p(B)}.$$

If we apply this to what we would like to learn, $p(\mathbf{\theta} \mid \mathbf{y})$, we arrive at a ***posterior distribution***.

- **Posterior Distribution**

The posterior distribution is the conditional distribution of the parameters given the data and represents what we know (including our uncertainty) about the parameters _after_ we observed $\mathbf{y}$.
Using Bayes' theorem, 

$$p(\mathbf{\theta} \mid \mathbf{y}) = \frac{p(\mathbf{y} \mid \mathbf{\theta})p(\mathbf{\theta})}{p(\mathbf{y})} \propto p(\mathbf{y} \mid \mathbf{\theta})p(\mathbf{\theta}).$$

Usually, we have many _conditionally independent_ measurements. _Conditionally independent_ doesn't necessarily mean the data are independent, just that, _conditional on the parameters_ they are independent.
When we have $N$ conditionally independent measurements, we use the joint likelihood to arrive at the _joint posterior_: 

$$p(\mathbf{\theta} \mid \mathbf{y}_{1:N}) \propto p(\mathbf{\theta}) \prod_{i=1}^N p(\mathbf{y}_i \mid \mathbf{\theta}).$$

This will be especially important for our purposes, since we will have multiple measurements that are observed _over time_.

Note that we use proportionality to drop the normalization constant 

$$p(\mathbf{y}) = \int p(\mathbf{y} \mid \mathbf{\theta})p(\mathbf{\theta}) d\mathbf{\theta}.$$

This is because this constant usually involves an intractable integration problem and a lot of common methods used for estimating the posterior distribution were designed to avoid this integration.
Other times, we can calculate the posterior in closed form and it's simple to figure out the normalization constant at the end of the process. This may seem like cheating or incorrect, but hopefully it will become (somewhat) transparent after we work some examples.
